AI security · open-source tool

SkillJail

AI agents can install “skills” (plug-ins) that run code on your computer, and some of them are built to steal data. SkillJail gives each skill only the files and websites it declares it needs and blocks everything else at the operating-system level, with a Seatbelt/Landlock jail and an egress proxy. It plugs into Claude Code, so every skill command runs sandboxed automatically.

~4,000real malicious AI skills tested against it
100%of targeted data-theft and break-in attempts blocked
✓legitimate skills kept working
Python · Linux Landlock · macOS Seatbelt · Claude Code
